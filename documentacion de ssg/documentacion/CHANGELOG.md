# 2025-11-09 — Versión Inicial (v1.0)

- Creación de la documentación base del sistema GYMWORK.
- Inclusión de guía de instalación y configuración (`manuales/guia-instalacion.md`).
- Adición de requisitos del sistema (`manuales/requisitos-del-sistema.md`).
- Integración de diagramas UML de arquitectura, componentes y casos de uso.
- Estructuración de la carpeta `capacitacion_aceptacion/` con ejemplos de UAT, cronogramas y datos de prueba.
