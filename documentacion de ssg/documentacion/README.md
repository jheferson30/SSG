# Objetivo

- Centralizar la estructura de la documentación del sistema **Sistema de Seguridad para Gym (SSG)** y facilitar el acceso rápido a cada componente técnico, funcional y de capacitación.

# Estructura

- `manuales/`
  - `manual-de-usuario/`
    - `index.md`
  - `manual-tecnico.md`
  - `guia-instalacion.md`
- `capacitacion_aceptacion/`
  - `plan.md` (Plan general de capacitación)
  - `plan-capacitacion-detallado.md` (Sesiones de formación por perfil)
  - `uat-plan.md` (Plan de pruebas de aceptación del cliente)
  - `plantillas/` (cronograma, criterios, incidencias, protocolo, actas)
  - `ejemplos/` (cronograma, casos, datos de prueba)
- `diagrams/` (diagramas `.mmd` y exportaciones `.svg`)
- `assets/`
  - `logo.svg`
  - `screenshots/` (capturas del sistema SSG)
- `config/` (configuración técnica y automatización)
- `pdf/` (exportaciones en formato PDF)
