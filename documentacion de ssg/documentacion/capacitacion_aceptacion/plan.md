# Objetivo

- Asegurar que usuarios y administradores adquieran las competencias necesarias para operar el software eficazmente.

# Alcance

- Usuarios finales, administradores y soporte. Cobertura: operación diaria, reportes y administración.

# Requisitos

- Entorno demo/sandbox, datos de prueba, materiales (manuales, guías rápidas) y facilitadores.

# Roles (RACI)

- Responsable: `<nombre/rol>`
- Aprobador: `<nombre/rol>`
- Consultado: `<áreas>`
- Informado: `<stakeholders>`

# Metodología

- Sesiones presenciales/virtuales, práctica guiada, casos reales y evaluación.

# Cronograma (resumen)

| Sesión | Tema | Duración | Público |
|--------|------|----------|---------|
| 1 | Introducción y navegación | 2h | Usuarios finales |
| 2 | Operaciones clave | 3h | Usuarios finales |
| 3 | Reportes y exportación | 2h | Usuarios finales |
| 4 | Administración y seguridad | 3h | Administradores |

# Materiales

- Manual de usuario, manual técnico (extractos), guías rápidas y videos.

# Métricas de éxito

- Asistencia ≥90%, evaluación ≥80%, tareas prácticas completadas y feedback positivo.

# Riesgos y mitigación

- Baja adopción: refuerzo con sesiones adicionales y soporte 1:1.

# Comunicación

- Calendario, invitaciones y recordatorios por correo/portal.
